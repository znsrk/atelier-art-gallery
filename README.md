## About

This is an art gallery website for our web development midterm. It has six main pages: Home, Gallery, Artists, Exhibitions, About, and Contact. There is also a form confirmation page.

The gallery contains six original SVG illustrations. The artists and exhibitions are fictional.

## Features

- Navigation and footer on every page
- Layouts for computers, tablets, and phones
- Artwork gallery using CSS Grid
- Bootstrap grid and utility classes
- Exhibition table
- Contact form with required fields and email validation
- CSS variables, Flexbox, positioning, and hover and focus styles
- Google Fonts and lazy loading for images

The contact form is a demo. It opens a confirmation page but does not send or save messages. The social links open Instagram and Pinterest homepages.

## Technologies

HTML, CSS, SVG, and Bootstrap 5.3.8 CSS. There is no JavaScript.

The fonts are DM Sans and Playfair Display from Google Fonts. System fonts are used if Google Fonts is unavailable.

Bootstrap CSS and its license are included in the vendor folder.

## How to open the project

Open index.html in a browser. No installation is needed.

Page content is in the HTML files. Styling is in css/style.css. Artwork is in the images folder. The navigation and footer are repeated in each HTML file.
